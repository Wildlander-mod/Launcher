# Obsidian Migration to Vite

## Migration Notes

The Obsidian vault at `~/workspace/personal/obsidian/launcher/Migration to Vite.md` tracks the outstanding tasks for migrating the launcher to electron-vite.

## Rule

**After any code change that completes — or directly relates to — a task listed in that file, mark it as done (`- [x]`) immediately.**

This includes tasks in all sections: _In Progress_, _Configuration & Build_, _Code Cleanup_, _Testing_, and _Open Questions_.

### How to apply

1. After implementing a change, read `~/workspace/personal/obsidian/launcher/Migration to Vite.md`
2. Identify any items that are now complete as a result of the change
3. Update them from `- [ ]` to `- [x]` using the Edit tool
4. If a task is partially complete (e.g. one sub-item done), tick only the completed sub-item and leave the parent unchecked until all sub-items are done
